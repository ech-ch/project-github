# project-github
Repository für das Projekt zur Entwicklung für eine Modularisierung der Standardisierung

# Vorgabe für Ordnerstruktur:
mein-repository/  
├── .github/                  # GitHub-spezifische Einstellungen  
│   ├── ISSUE_TEMPLATE/       # Vorlagen für Fehlerberichte/Anfragen  
│   └── PULL_REQUEST_TEMPLATE.md  
├── docs/                     # Ausführliche Dokumentation & Konzepte  
│   ├── protocols/            # Sitzungsprotokolle der Fachgruppe  
│   └── guides/               # Anleitungen und How-Tos  
├── src/                      # Der eigentliche "Code" oder die Arbeitsdateien  
│   └── assets/               # Bilder, Logos, Vorlagen  
├── tests/                    # (Falls Programmiercode existiert) Testskripte  
├── .gitignore                # Bestimmt, welche Dateien GitHub ignorieren soll  
├── LICENSE                   # Die Lizenz (z. B. MIT für Open Source oder ein Hinweis auf internen Code)  
└── README.md                 # Die Startseite des Repositories (Das Wichtigste!)
